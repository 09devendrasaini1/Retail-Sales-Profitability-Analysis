# Retail Sales & Profitability Analysis

## 📊 Project Overview

This project analyzes retail sales performance, profitability, loss orders, regional performance, product performance, and the relationship between discounts and losses.

The objective is to identify key business trends and provide actionable insights using SQL, Excel, and Power BI.

## 🛠️ Tools Used

* Excel
* SQL
* Power BI
* CSV Dataset

## 📁 Dataset

The project uses a Superstore retail sales dataset containing 51,290 records and 21 original columns.

Key fields include:

* Order ID
* Order Date
* Ship Date
* Region
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit
* Shipping Cost
* Customer Segment

## 📈 Key Analysis

The analysis covers:

* Sales performance by region
* Profit by category
* Loss orders by category
* Profitability by sub-category
* Loss rate by region
* High-discount orders and loss orders
* Shipping time analysis
* Overall sales and profitability

## 🔍 Key Insights

* Total Sales: **$12.64M**
* Total Profit: **$1.47M**
* Total Orders: **51,290**
* Overall Loss Rate: **24.46%**
* Central region generated the highest sales at approximately **$2.8M**.
* Technology generated the highest category-level profit.
* Tables had the highest loss rate at approximately **57.61%**.
* Copiers were the most profitable sub-category by total profit.
* Orders with discounts above 50% had a **100% loss rate** in this dataset.

> High discounts and losses show a strong association in this dataset; this analysis does not establish that discounts directly caused the losses.
